몸짱소울 앱 설치용 파일 묶음 (5번째 버전)

이 폴더 안의 파일을 그대로 인터넷 주소(https)에 올리면,
폰에서 그 주소를 열어 앱처럼 설치할 수 있어요.

- index.html : 앱 본체
- manifest.webmanifest, icon-*.png, apple-touch-icon.png : 앱 이름과 아이콘(금색 육각 방패에 검)
- sw.js : 한 번 열어 두면 인터넷이 없어도 열리게 해 주는 파일

이미 예전 버전을 올려 두었다면, 이 폴더 안의 파일들을 같은 자리에 다시 올려서 덮어쓰면 돼요.
폰에 이미 설치한 앱은 아이콘이 바로 안 바뀔 수 있으니, 지우고 다시 설치해 주세요.
앱을 또 고쳐서 올릴 때는 sw.js 맨 위의 VERSION 숫자를 올려 주세요.
